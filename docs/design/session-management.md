# 会话管理设计

当前设计已在独立 `` 界面中实现，全部使用演示数据；创建、重命名、控制权和结束操作只改变内存中的展示状态。

## 管理入口

左侧新增「会话管理」，快捷键 `Cmd/Ctrl+2`。这里汇总从桌面界面、CLI、MCP 创建的所有终端实例，包括未在工作台打开的会话和已经结束的会话。

| 位置 | 管理对象 | 主要操作 |
| --- | --- | --- |
| 连接管理 | 保存的主机、认证和启动命令配置 | 编辑配置、导入、创建会话、查看此连接的活跃会话 |
| 会话管理 | 每一个具有独立 ID 的终端实例 | 搜索筛选、打开、重命名、接管、结束、查看记录 |
| 工作台 | 当前打开的会话视图 | 标签切换、分屏、观察输出、终端操作 |
| 历史记录 | 按 session 区分的操作记录 | 默认查看当前会话；全部会话分组展示，支持 AI / MCP / CLI / 人工筛选及输入输出详情 |

一个连接可以有多个会话，例如 `prod-web-01` 同时用于「生产服务巡检」和「部署日志」，它们的 ID、终端进程、控制权和生命周期独立。标签数量与活跃会话数量分别展示。

## 会话管理页面

顶部显示活跃数量、工作台已打开数量和后台保留数量。待接管会话单独提示，点击可直接筛选并查看详情。

主区域采用列表加详情侧栏：

- 列表有「活跃 / 待接管 / 已结束 / 全部」视图，可按创建来源筛选，支持搜索名称、目标主机、客户端和会话 ID。
- 每行显示会话名称、连接名称、ID、当前状态、创建来源、控制权和最近活动；小窗口内表格可以独立横向滚动。
- 工作台图标表示当前已有标签，后台会话可以随时打开，打开时复用原会话。
- 右侧详情包含目标地址、创建来源与时间、会话时长、工作台可见性、控制权、最近命令和此会话的操作记录。
- 多选仅针对活跃会话；批量结束弹窗列出目标会话，并在有命令执行时给出明确提示。

状态文案使用「等待输入」「执行中」「待接管」「已结束」。待接管是需要人工处理的提示，后续接入时应结合服务端状态与等待原因，不能简单替代核心会话状态。

创建来源和当前控制权分开展示：CLI / MCP / 界面描述从哪里创建，AUTO / MANUAL 描述谁能继续写入。创建来源不会随接管而改变。

## 关键操作

| 操作 | 设计行为 |
| --- | --- |
| 新建会话 | 选择已有连接，可填写独立会话名称；每次创建新的终端实例 |
| 打开会话 | 在工作台打开原会话；已经有标签时切换到该标签 |
| 收起标签 | 只移除视图，会话仍在活跃列表；最后一个标签收起后展示回到会话管理的入口 |
| 重命名 | 修改会话的展示名称，不修改主机配置和会话 ID |
| 接管 / 交还 | 展示当前会话的 MANUAL / AUTO 控制状态，不影响其他会话 |
| 结束会话 | 独立确认；说明终端进程和任务停止，收起相关标签，将会话归入已结束并保留记录 |
| 查看已结束会话 | 展示结束时间和记录，不显示可继续输入的终端入口 |

工作台标题区「会话管理」、最近会话区「全部会话」、终端菜单与侧栏「管理此会话」、连接列表的会话数和底栏的活跃会话数，都能回到集中管理入口。

本轮没有连接真实后台、启动终端进程、修改数据库或接入 CLI / MCP。

## 操作记录与回调消息

沿用「历史记录」页面，不新增独立审计页面。默认定位到工作台当前 session；从会话详情进入时定位到该会话，包含已结束的会话。选择「全部会话」时先按 session 分组，每组显示会话名、ID 和状态；同一连接下的不同 session 不合并。

每条演示记录独立包含操作者（AI / 人工 / 系统）、入口（MCP / CLI / 桌面端 / 后台服务）、时间、动作、输入、输出、执行状态、耗时，以及适用时的退出码。「AI」聚合 AI 发起的 MCP 与 CLI 操作，「人工」包含桌面与 CLI 人工操作；入口不能用于推断操作者。命令失败、持续执行和等待输入分别展示，未退出的任务不显示成功退出码。

记录展开查看输入、stdout / stderr 和执行结果；会话侧栏复用同一份演示记录，工作台仅展示当前 session 的最近操作。后续接入真实后台时，结构化任务的输出和退出码应使用实际任务结果；原始终端流、自由输入和控制事件不能虚构命令边界或退出码。

设置中的「Webhook 回调」承接外部服务发送到 Shellink 的消息，展示回调接收地址、事件、接收时间及完整 JSON。消息中的 sessionId 可用于跳转到对应操作记录；清空回调消息不影响会话审计。当前仅在页面内演示搜索、筛选、复制、清空与恢复示例，没有启动接收端、请求后台或订阅事件。
