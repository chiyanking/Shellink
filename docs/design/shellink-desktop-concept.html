本地服务可用

在 AI 客户端添加 Shellink

复制配置到支持 MCP 的客户端。配置中的路径会指向本机安装位置。

MCP 配置 · 路径示例
{
  "mcpServers": {
    "shellink": {
      "command": "C:\\Apps\\Shellink\\bin\\shellink.exe",
      "args": ["mcp"]
    }
  }
}

从命令行直接操作

AI 使用结构化结果读取状态、提交任务和获取输出。

CLI 示例
shellink session list --json
shellink session state SESSION_ID --json
shellink session exec SESSION_ID --command "uname -a" --json

可执行文件：C:\Apps\Shellink\bin\shellink.exe
